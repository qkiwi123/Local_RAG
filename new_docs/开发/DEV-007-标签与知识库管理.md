## 3. 核心流程与输入输出

tag_store规范化路径、创建父级、维护子树；resolve_document_ids将多标签转换为文档ID并集。父级含子孙，空标签列表表示全库，选定标签但无文档则检索集合为空，不能退回全库。

GET /documents只列ready文档。q是去首尾空白、不区分大小写的名称子串匹配，通配符按字面处理；与tags结果取交集，不能解释为全文检索。前端防抖请求，把后端结果作为列表权威。

标签删除保留文档，只移除对应关联；独立建标签不自动挂文档。文档标签PUT用于已上传文档分类调整。

## 4. 异常、实际结果与验证

非法路径返回校验错误；重命名冲突不应产生半棵树。现有API、存储与React入口均可定位，本次未写数据库。测试见[TEST-004](../测试/TEST-004-标签与React交互.md#cases)，检索范围的三模式一致性见[TEST-002 检索质量与性能](../测试/TEST-002-检索质量与性能.md)。

## 5. Bug修复与后续
