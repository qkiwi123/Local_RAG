## 1. 来源需求与设计目标

关系：实现[REQ-001 文档入库与可定位来源](../需求/REQ-001-文档入库与可定位来源.md)的文档管理及[REQ-003 会话与知识库交互](../需求/REQ-003-会话与知识库交互.md)的检索范围与界面交互。将知识库范围设定和会话输入放在用户容易理解的位置，避免上传/标签面板长期挤占文档列表。

<a id="tags"></a>
## 2. 标签数据模型与查询

SQLite保存tags与document_tags，tag_path用斜杠表达层级。选父级包含子孙，多选标签取并集；名称q与标签范围取交集。独立创建空标签不挂文档；删除标签只解除关联，不能删除文档。

标签先解析为allowed_document_ids，再进入Dense/BM25检索；不为标签修改重写Chroma的每条chunk。重命名子树需更新标签与关联并保持完整性，非法路径拒绝。

## 3. React信息架构

| 区域 | 职责 | 状态归属 |
|---|---|---|
| AppShell | 紧凑导航：对话、知识库、设置 | 路由 |
| ChatPage | 会话列表、消息时间线、输入与范围 | useChatController |
| KnowledgePage | 文档列表/卡片、名称搜索、标签筛选 | 服务端文档与本地筛选 |
| 任务抽屉 | 上传、标签管理、文档预览、Trace | 按需加载/展开 |
| SettingsPage | 草稿、保存、恢复默认和连接测试 | 后端配置为权威 |

检索范围位于时间线下方、输入框上方，属于下一请求参数；上传是暂存→确认→逐文件结果，失败项可单独重试。桌面分栏与抽屉可调宽，移动端使用单栏/全宽抽屉。

## 4. 接口、异常与兼容

主要接口由[DEV-007 标签与知识库管理](../开发/DEV-007-标签与知识库管理.md)记录；API客户端见[client.ts](../../web/src/api/client.ts)，NDJSON解析见[stream.ts](../../web/src/api/stream.ts)。409触发服务端重同步，上传失败不能通过简单刷新抹掉待重试项。

业务配置不写localStorage；面板宽度等UI偏好与业务配置区别管理。旧Streamlit仍保留，但React是主要验收入口。

## 5. 方案取舍与任务

采用文档列表为主、右侧操作面板按需展开的方案，避免多列固定卡片在Windows缩放时重叠。组件测试只覆盖行为，几何布局仍需真实浏览器验收；Ant Design打包体积警告是已知问题，尚未记录当前拆包优化结果。

实现[DEV-007 标签与知识库管理](../开发/DEV-007-标签与知识库管理.md)、[DEV-008 React主前端](../开发/DEV-008-React主前端.md)；验证[TEST-004](../测试/TEST-004-标签与React交互.md#cases)。历史重构原因见[UX重设计](../../docs/superpowers/plans/2026-08-15-phase-3-frontend-ux-redesign-plan.md)。
