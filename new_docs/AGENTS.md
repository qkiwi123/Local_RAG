# new_docs 文档维护规则

创建/更新：2026-08-27。适用范围：本目录。依据用户提供的项目文档治理要求；不改变原docs、根README或根级Agent配置。

开始维护前读[README](./README.md)、相关类别导航和[OPS-004](./运维/OPS-004-文档维护与变更流程.md)。先搜索现有ID/主题；简单调整更新原主题，独立生命周期才分配新ID。

所有核心文件保持唯一ID、创建/更新日期、合法状态、实际实现/验证边界、关联区和变更记录。REQ→DES→DEV→TEST/OPT/OPS双向追踪；Bug记录发现、修复位置及回归，未完成不假装闭环。章节级引用使用稳定锚点并说明关系。

文档内使用相对Markdown链接，不放本机绝对路径和真实密钥。历史原始报告不改日期/数值冒充新结果；未执行、待确认和环境阻塞单列。需求变更同步下游，设计变化同步DEV，不只改代码。

每次变更更新分类README，重要功能更新总导航；运行工具/check_docs.py。检查器不替代代码事实核对或真实业务测试。原文件hash保护仅用于本次整理验收。
