当前基准：hybrid；Dense/BM25/Reranker候选15；distance≤0.67；BM25 k1=1.5、b=0.75；RRF常数60；final Top5；每文档最多3块。
BGE large zh、Reranker v2 m3、cuda:0、重排FP16、batch32/8、max_length512、recursive400/80/max_tokens480保持不变。

需要区分四个事实：

1. Dense、BM25、重排、最终TopK有独立设置，但**融合池没有独立参数**，当前为`max(Dense K, BM25 K, Reranker K)`（重排关闭时第三项为final K）。不能声称所有阶段已经完全解耦。
2. 旧`retrieval-sweep`主要扫重排K，且每次会从空测试库入库；不足以直接承担本次多参数、分区、同索引实验。
3. 现有距离阈值离线工具在最终结果上过滤，不等价于Hybrid真实的Dense过滤→RRF→重排。不能拿旧Top15结果推算Top50召回。
4. `RefusalGateSettings`仍拒绝enabled=true，检索核心没有实际门控算法；实验室模拟门控不等于S7已上线。

数据仍draft，允许按已接受的预基线范围做探索；人工verified、全库完备性和新的盲测均未完成。审核边界见[TEST-006](../测试/TEST-006-数据集与评测验收.md#tuning-gates)。

### 3.2.1 Dense差异补充诊断

诊断报告及机器汇总分别为[Dense差异来源与波动范围](../../eval/crud_rag_1000/v3_1/tuning/v35-a-baseline-20260829/diagnostics/Dense差异来源与波动范围-20260829.md)和[dense-variance-analysis.json](../../eval/crud_rag_1000/v3_1/tuning/v35-a-baseline-20260829/diagnostics/dense-variance-analysis.json)。

- 已确认来源类别：当前Chroma 1.5.9库有2914条embedding，但持久化HNSW只到`seq_id=2000`，其余914条操作处在queue/WAL尾段；全新隔离索引的“入库同进程→退出→重开”对照能复现每侧3个候选替换。查询Embedding哈希跨进程不变，共享候选distance逐位相同，BM25稳定，排除GPU Embedding随机性、BM25和Reranker作为起点。
- 强证据推断但未逐指令证明：queue重放配合HNSW近似检索及`num_threads=20`形成不同进程状态；未修改Chroma原生代码记录具体线程调度，因此不声称已经定位到某一条图边的构建次序。
- 历史run→A的72题范围：10题Dense集合变化，7题可回答、3题不可回答；每侧替换1—4个，Jaccard 0.579—0.875，共享候选最大位移3。15个独立进程重复10题后，6/10题出现2—3种状态，始终共同保留12—15个候选，并集15—17个，最坏每侧替换2个、Jaccard 0.765；与精确余弦Top15的实测ANN Recall@15为73.33%—100%。这些是当前索引和题目的经验范围，不是HNSW理论上界。
- 5个独立进程共150次完整链路中，10题的Dense/BM25/RRF/Reranker/最终Top5变化题数依次为5/0/3/3/2。同一进程内重复全部稳定；最终变化的1道可回答题只在第5位交换两个非Gold块，两篇Gold及证据均保留，另1道为不可回答题，本次未观察到质量指标变化。

用户确认把该差异视为受控ANN噪声并继续B；实际采用同一长生命周期进程、首尾重复control的策略。control逐阶段72/72一致，因此本轮无需重建`num_threads=1`索引；该结论不取消未来跨进程比较的控制要求。

## 4. 拟议验收门槛、分支与风险

以下门槛已用于F并导致不采用；B/C/D/B2/E/F实际结果以第3.3—3.7节为准，未达到的目标不回填成结果：

- 召回侧：在同split、同进程、同TopK预算上不低于同期control的文档Hit/Recall、all-gold与证据覆盖。D已用首尾control确认同进程稳定；跨进程C/D的57/60与56/60差异不能当参数退步或收益。
- 门控侧：优先0道可回答误拒答；探索上限暂列development≤1/60，同时不可回答拦截≥9/12。validation要求0/20可回答误拒答、至少3/4不可回答拦截，并保持基准19/20完整gold召回。
- 性能侧：同机同索引复测P95不超过同期基准的1.5倍作为初始成本警戒线；超线但质量明显改善时提交收益/成本选择，不自动采用也不隐藏结果。
- 不使用四舍五入后的百分比掩盖单题退步；误拒答和新增漏证据逐题列出。任何候选若无法同时满足质量/门控/成本约束，可以结论为“暂不采用”，不能为了结项放宽门槛。
- validation只有4道不可回答，一题即25个百分点，不能据此声称已获得可靠的总体拒答准确率。正式盲测需要另行补样，当前不擅自增加题目。

必须说明并等待决策的分支：复制索引不兼容、GPU失败/OOM或需要降精度/缩batch、扩大E—F预定候选范围、主模式切换、独立融合池改造、切分/Embedding模型变更、质量与延迟取舍、标签疑义以及S7/生产接入。

BM25 TopK/k1/b及RRF已按用户追加授权在B2完成坐标扫描；结果是K50能追平但不能超过Dense，故不继续扩大为笛卡尔积或切换Hybrid。切分实验仍保留为条件分支：只有主要瓶颈确认为chunk证据断裂时才比较300/60、400/80、500/100。
切分会改变索引与证据对齐，需要新实验子目录和新基准，不能混入本轮同索引比较；不会为了修复exact指标外观就重切全库。
