## 1. 问题与发现

[structured-v2迁入审查](../../docs/数据链路调优反馈分析与结构化v2迁入审查.md)发现eval引用有效性硬编码structured-v1，导致没有page_number的v2 Markdown/PPTX引用被低估。追踪入口[TEST-007 缺陷与历史反馈追踪](../测试/TEST-007-缺陷与历史反馈追踪.md)。

## 2. 影响与原因

这是评分器对结构契约判断错误，影响报告的citation指标；不能据此认定原问答引用实际无效。

<a id="fix"></a>
## 3. 修复实现

关系：修复[DEV-011评测指标](../开发/DEV-011-评测CLI与数据集.md#bug-fixes)。[eval/metrics.py](../../eval/metrics.py)按unit_id、location_label、locator_kind判断结构化引用并兼容legacy路径，不依赖特定parser版本字符串。

<a id="regression"></a>
## 4. 回归结果与结论

[test_eval_metrics.py](../../tests/test_eval_metrics.py)有幻灯片和章节无page_number用例：test_structured_location_is_valid_without_page_number、test_structured_v2_section_without_page_number。原审查追加的2026-08-16实施记录确认修复与测试更新。

修复状态：历史已修复，代码与用例已核对；本次未运行。回归入口[TEST-006 E04](../测试/TEST-006-数据集与评测验收.md#cases)；历史报告不能因此自动视为已重新计分，新评测应注明评分器版本。
