## 2. 环境与安装

后端依赖以[requirements.txt](../../requirements.txt)为准，旧CPU环境为.venv，GPU为.venv-gpu；前端以[package.json](../../web/package.json)和lockfile为准。仓库记录Python 3.14已用过，但本次未重装验证。

CPU环境的准备示例（在根目录，使用已安装Python）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path -LiteralPath .env)) { Copy-Item -LiteralPath .env.example -Destination .env }
```

不要在已有环境里盲目重装GPU PyTorch。GPU历史组合见[OPT-002 CPU到GPU检索迁移](../优化/OPT-002-CPU到GPU检索迁移.md)；新机器需按硬件另行验证。BGE和Reranker是local_files_only加载，运行前准备本地缓存。首次启用LLM需环境Key或可读DPAPI Key；不使用LLM时设LLM_ENABLED=false。

## 3. 配置分类

| 配置 | 职责/注意 |
|---|---|
| METADATA_DB_PATH / CHROMA_PERSIST_DIR / UPLOAD_DIR | 主数据路径，验收需隔离 |
| LLM_ENABLED / DEEPSEEK_* | 问答模型默认；运行时覆盖可能优先 |

| RETRIEVAL_TRACE_ENABLED | 默认false；含候选全文 |
| OCR_* / VISION_* | OCR识别层默认关闭，启用可能外传图片 |
| PREWARM_MODELS | 默认true，启动后台加载模型 |

完整参数在[config.py](../../backend/config.py)与[.env.example](../../.env.example)；不要把真实.env粘贴进文档。

## 4. 构建、启动和停止

首次在web目录执行npm.cmd ci和npm.cmd run build；回到根目录：

```powershell
.\scripts\start.ps1
.\scripts\start.ps1 -InferenceProfile cpu
.\scripts\start.ps1 -Reload
```

以上是三种替代选择，不要连续执行。默认gpu，脚本同时启动React托管后端和旧Streamlit；已有web/dist不会自动重建，因此前端源码更新后手动build。

```powershell
.\scripts\stop.ps1
```

等价入口为start.ps1 -Stop。脚本受执行策略限制时可在确认信任后使用powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1；无需永久修改执行策略。
