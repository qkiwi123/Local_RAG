## 2. 配置与密钥

有效设置由部署默认、SQLite覆盖和DPAPI Key合并。runtime_secrets.bin默认位于metadata同目录，用户级DPAPI保护；读取settings只返回脱敏状态。环境文件变化不会自动覆盖已保存runtime字段；请求Trace记录当时revision。

当前无认证。不要向公网暴露API、Trace或OCR图片；连接测试允许服务端请求模型地址，远程使用前需要认证与出站限制。历史反馈9/18涉及Key安全，是否已经轮换不能从旧记录确认。

## 4. 安全日志与操作原则

只记录配置revision、字段名、错误类型和脱敏模型身份。日志和Trace含业务文本，分享前人工检查。不要把.env整体输出到终端或工单；密钥只按必要键更新，避免编码变化把参数吞进注释。

Windows PowerShell脚本修改后检查编码、语法与正常/reload路径；不要引入CMD包装或通过整目录删除“修复”状态。遇到异常应先只读核查，再确认影响范围。
