# Windows W3：启动、停止和基础维护

2026-10-24实现，当前仍为内部验证目录，不是已经完成W4/W5的正式发布ZIP。W1/W2历史结果保留；总体进展见[OPS-005](../../new_docs/运维/OPS-005-Windows单人本地发布与初始化方案.md#w3-result)、[DEV-012](../../new_docs/开发/DEV-012-服务托管与启动停止.md#w3-result)、[TEST-009](../../new_docs/测试/TEST-009-本地运行与回滚验证.md#w3-result)。

## 四个入口

| 文件 | 行为 |
|---|---|
| 启动.cmd | 优先检查GPU，启动隐藏后台，等待实际模型预热后打开React设置页；不可用时说明并询问CPU |
| CPU启动.cmd | 显式CPU，仍使用Hybrid、持久化BM25和Reranker；重排FP32 |
| 停止.cmd | 通知匹配实例正常退出，等待请求、索引任务和预热完成；超时需用户确认强制结束 |
| 维护.cmd | 打开目录/日志、预览并确认清理可重建文件、移除前停止与备份提示；不会自删除 |

用户从目录内双击即可，不需要打开PowerShell或改变脚本执行策略。关闭浏览器不会停止后台。默认仅127.0.0.1:8000，成功后打开`/settings?build=前端摘要`；缺少预构建React时拒绝启动，不回旧Streamlit。源码启停仍是原入口，不要混用两套目录。

GPU检查在独立短进程完成，不在启动器内驻留双模型；后台实际编码/重排预热成功后才打开页面。GPU显存不足只将Embedding/Reranker批量32/8降到16/4重试一次，不换模型、不减候选15/top_k5；仍不足再询问CPU，不默默切换。缺包/模型、清单错误、数据库不兼容不伪装成GPU问题。CPU模式不禁用重排。

## 实例与停止保护

运行状态只在state，包含随机实例ID、PID/创建时间、相对解释器、端口、根摘要和资产/前端摘要，不保存Key或文档内容。command.lock串行启动/维护，service.lock由后台服务持有。重复启动只认同根、同解释器、双向创建时间与命令行实例标识都匹配的进程，再核对健康身份和前端版本；单纯HTTP 200、同进程名、陈旧PID或另一个目录均不能冒认。

停止采用实例绑定的state停止请求文件，不提供HTTP停止接口。正常退出等待请求和后台任务，预热仍在进行时也先等待资源释放；强制结束需确认，并再次核对捕获进程身份。启动失败只回收本次Popen持有的子进程，不按名称或端口批量终止。初始化期间的停止会请求取消启动；当前资源校验阶段可能需等待其结束。旧源码stop.ps1的两处单向时间比较已改为绝对差，未在生产服务上执行该脚本验证。

便携HTTP检查只接受当前端口的localhost/127.0.0.1 Host及同源Origin，跨站写入即使使用简单text/plain表单也拒绝；源码Vite/CORS行为不变。此措施不是账号认证，不承诺抵御本机恶意程序或不同Windows用户。

## 缓存与移除

目前清理菜单只管理两类明确文件：分词缓存`temp/jieba.cache`或`cache/jieba.cache`；资源校验缓存`state/verified-assets.json`。清理前列出大小、确认且要求停服。其余缓存/temp、未知文件、data、两份模型、OCR原图/视觉缓存及日志均保留，不做泛化递归删除。清掉校验缓存后下次启动重新校验完整资源。

移除前准备只停止当前目录实例并显示提示：按需备份到目录外，再手动删除整个目录；删除会包含知识库、密钥密文、模型和运行环境。不会清除外部原件、备份、HF全局缓存、浏览器/系统记录，不操作注册表、服务、自启或防火墙。

## 维护者装配与验证

以下仅在维护者电脑执行。新目标必须为项目build下不存在的子目录；从W1复制固定运行时/模型，再装入当前backend/launcher、四个CMD和已构建React，不复制个人.env/data/eval。没有生成ZIP，不会把整个仓库压缩发布。

```powershell
.\.venv-gpu\Scripts\python.exe deploy\windows\prepare_w3.py --runtime-bundle "build\windows-w1\中文 空格 验证包" --output "build\windows-w3\新的验证目录"
```

实际验证目录为`build/windows-w3/便携 启停验证-20261024/`。最终本机结果和原始报告摘要见[W3结果](./w3-result.json)：14文件237通过/3项链接权限跳过，其中W3为44通过/1跳过；真实CMD/HTTP/GPU及CPU重启链路通过，验证服务已全部停止。资源清单34,158文件、7,217,838,536字节是未压缩载荷，不是ZIP大小。

W3以portable-manifest.json为当前资产清单；w1-manifest.json仅保留装配输入历史，不用于W3运行校验。首次读取全部资源SHA-256，后续核对路径/大小/修改时间并重新哈希变化文件；清单或根变化会重新完整校验。这是本地完整性检查，不是数字签名认证。主数据不在资源清单中。

```powershell
.\验证目录\runtime\python.exe .\验证目录\validation\probe_w3.py
```

探针只允许全新W3目录，使用合成TXT和临时回环端口、真实本地模型与HTTP；覆盖并发启动、CMD转发参数/独立cwd、React设置页/JS类型、Host/Origin、上传/检索、外部HTTP200端口、不匹配PID、初始化取消、正常/显式强制停止、CPU重启和维护保留范围。浏览器启动目标用单测核对，探针用--no-browser，不冒充真实桌面双击/浏览器人工验收。API生成与OCR关闭，不调用远程模型。

开发修复可先停止验证服务，再执行`prepare_w3.py --refresh-app --output <W3目录>`；先完整检查旧资产，仅更新已有应用/前端/入口与清单，不升级运行时或改业务data。未知文件不覆盖，移除代码文件时须新建验证树。此入口不是用户升级器。

## 后续发布边界

W4仍需React可重复构建、原wheel来源/VC再分发许可、最终白名单/使用说明及ZIP；必须重新装配空包，不能直接压缩含合成data、状态和日志的W3测试目录。W5仍需无NVIDIA/无驱动干净机、真实浏览器、完整系统外写、质量与规模、移动/备份/删除验收。后续ZIP导出目标按用户本轮指定，保存在本机忽略的`build/windows-release/output-preference.json`，不把本机绝对路径硬编码到公开代码或发布包。本轮未导出ZIP，也未向该外部目标目录写文件。
