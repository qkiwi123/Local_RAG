## 已实现的最小边界

- 不设置`RAG_DISTRIBUTION_MODE`时仍为源码模式，读取原环境/.env，原默认值不变。
- `RAG_DISTRIBUTION_MODE=portable`不读.env，不继承原Key、数据路径、模型或检索参数。仅接受`RAG_PORTABLE_DEVICE=cuda:0|cpu`，默认GPU；设备不支持就报错，不静默切CPU，不关闭重排。
- 相对随包backend定位根，数据/cache/temp在该根内，模型只从models/embedding与models/reranker读取。丢文件明确失败，不使用个人HF缓存补齐，不下载。
- 新工作空间默认关闭生成/OCR，保留Hybrid、bm25s_mmap、Reranker、候选15/top_k5、recursive 400/80。GPU重排FP16，显式CPU为FP32；页面非设备设置仍复用现有管理器。
- data/workspace.json保存稳定身份、随机corpus ID、schema/模型/运行锁合同和首代日志；无标识旧data、合同不匹配或非schema5数据库在业务导入前拒绝，原数据不改。运行锁暂要求完全一致，不等于已有任意跨版本升级能力。
- 空库等待上传；首次非空ready语料自动创建并校验Sparse，后续上传/删除/设置变化/重启沿用原协议。提交中断只可复核并重放日志指定候选，已发布库丢active不重新开放首发。源变化或候选损坏时保留故障，不能恢复旧数据。
- 本地快照oracle最多65查询，仍校验构建和mmap重载的排序/分数；源码仍使用原120题。不把本地校验当作人工回答质量评测。

## 维护者装配

只能使用被忽略的build子目录作为新目标；存在就拒绝，不覆盖。先校验W1全部资源，复制runtime/models/locks/licenses及backend Python源码，不带.env、个人data、eval、Node或开发venv，也不复制前端构建。

```powershell
.\.venv-gpu\Scripts\python.exe deploy\windows\prepare_w2.py --runtime-bundle "build\windows-w1\中文 空格 验证包" --output "build\windows-w2\新的验证目录"
```

当前实测目录为`build/windows-w2/便携 应用验证-20261024-r2/`。W2清单沿用w1-manifest.json文件名以复用校验器，但stage明确为W2，不能被W1 complete当作W1原型处理。清单只含运行资源与应用源码，不包含生成的data/cache/temp/reports。

开发过程中可以在既有W2验证树执行下列显式刷新；先验证原有清单，再仅更新backend/验证脚本与清单，不升级运行时/模型、不改业务data。不对生产目录或W1原型执行。

```powershell
.\.venv-gpu\Scripts\python.exe deploy\windows\prepare_w2.py --refresh-app --output "build\windows-w2\便携 应用验证-20261024-r2"
```

这是内部阶段工具，W4仍须完成原始wheel来源、VC再分发许可、完整发布清单/React与可重复ZIP。不要把installed-RECORD资源摘要当作原wheel哈希或公开分发授权。

## 真实应用验收

探针使用ASGI直接执行真实FastAPI路由；不启动TCP服务或浏览器，不mock模型、Chroma、切分器、检索或重排。新目标首次运行六份公开合成TXT资料，保存BM25参数并删除一份；重启阶段核对设置、文档、工作空间和索引仍在，实际设备及重排精度正确。

```powershell
.\新的验证目录\runtime\python.exe .\新的验证目录\validation\probe_w2.py --device cuda:0 --phase first --report gpu-first.json
.\新的验证目录\runtime\python.exe .\新的验证目录\validation\probe_w2.py --device cpu --phase restart --report cpu-restart.json
```

first拒绝已有metadata.db或已完成的测试夹具，只能用于新W2验证树。不要对个人知识库运行合成资料验收。restart须先完成first。原始JSON留在该目录reports，摘要保存报告hash；早期版本报告和合成副本保留为历史，不混作最终结果。

本轮故意污染PYTHONHOME、PYTHONPATH、HF_HOME、DEEPSEEK_API_KEY、LLM_ENABLED和UPLOAD_DIR，随包解释器/便携配置仍使用自己的资源，生成/OCR保持关闭。Windows事件循环初始化需要内部回环；受限环境曾阻塞在socketpair accept，经权限机制在受限环境外运行后通过，未修改系统设置。随后审计拒绝网络和已覆盖包外文件写入；ASGI请求本身不使用网络。原生DLL/注册表/完整进程树外写仍待W5实测，不能承诺绝对零痕迹。

## 日常启动与移除还没有交付

本轮不提供日常可双击启动包。W3再实现启动、显式CPU、停止、基础维护、单实例及Host/Origin限制；W4制作完整ZIP；W5验证界面、真实资料、移动/备份/移除与外写。无NVIDIA且无驱动Windows仍待外部电脑，本机CPU通过不能替代。

以上验证命令退出后服务与后台任务结束；本轮没有停现有服务、修改个人.env/data或源码启停脚本，也没有调用远程生成/识图API。测试副本只含合成资料，清理时仅处理明确的build验证子目录，不删除仓库、生产data、已有venv或HF全局缓存。
