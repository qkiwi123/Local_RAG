- 使用P2活动generation `p2-1000-20260903-r5`，1000篇、2914 chunks。

- 固定相同Dense候选后，RRF顺序、Reranker输入和最终Top5重放：均为120/120一致。

结果：[result.json](./result.json)。验证脚本：[verify_p3.py](./verify_p3.py)。该脚本复用优化前保存的同题Dense候选和Reranker分数；没有重新运行GPU模型，也不是P4性能对照。

## 首轮失败与口径修正

首轮业务日志对照的全部排名和最终结果均一致，但分数最大差`2.8421709430404007e-13`，因此原先“与序列化旧日志分数逐位相等”的额外条件失败。原因是旧业务按Chroma返回顺序累计平均IDF，而确定性generation按稳定chunk ID排序；IEEE-754加法顺序产生约`1e-13`差异。P3改为有序结果严格相等且分数差不超过`1e-12`，并保留实际差值；P2针对其固定排序oracle的分数差0结论不变。
