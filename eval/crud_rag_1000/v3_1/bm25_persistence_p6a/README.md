# BM25 P6-A 接手检查与隔离验收

日期：2026-09-08。范围：[OPT-005 P6-A](../../../../new_docs/优化/OPT-005-BM25持久化稀疏索引.md#phase-p6a-result)。结论：单服务进程的生命周期实现及隔离回归通过；停在P6-B生产影子构建之前。

## 接手完成度与修复

接手基准为分支`feature/rag-v2-optimization`、提交`6a5bb4f`之后其他工具留下的未提交修改。已有写前dirty、后台线程、查询错误、状态字段和生产CLI主体，但缺少可靠的并发发布门禁，且测试无法完整通过。因此没有给出缺乏依据的完成百分比。

| 检查项 | 接手发现 | 补完结果 |
|---|---|---|
| 持久失效 | 有写前标脏；文档提交/失败补偿与发布不互斥 | 最外层文档事务与发布共锁；标脏失败拒写；部分写入抛错也失效内存缓存 |
| 发布一致性 | 最终复核到切换有空档；复用旧代分支缺少同等保护 | 源revision、正文/metadata摘要、有效合同复核与切换处于同一临界区；变化候选作废并排队 |
| 存储一致性 | 后台只扫描Chroma，没有核对登记表 | SQLite只读quick_check、ready文档ID及逐文档chunk数须一致，失败补偿残余不得成为ready索引 |
| 参数与缓存 | worker使用启动参数；清缓存把绑定revision归零 | 使用设置管理器的有效k1/b，保存前失效；构建中参数变化废弃候选；清句柄不清语料绑定 |
| oracle | 后台仅3道通用哨兵；重载只验证mmap | 构建及mmap重载均用固定120题比较K=1/5/15/50有序结果及分数 |
| 恢复与停机 | 只比较数量；停机中的构建可能继续发布 | 启动核对完整摘要，新进程拒绝dirty；停机中的候选不发布；旧代句柄释放 |
| 首次/空库 | 上传可能自动创建首代；空库无限重试 | 缺初代返回needs_initial_generation；空库保持dirty并记录empty，下次写入再重建 |
| CLI保护 | 外部配置目录、SQLite WAL及逐文档对应保护不足 | 环境覆盖后精确路径/确认，production-语料ID、120题、WAL前后摘要、ID/数量核对和报告位置保护 |
| 测试可靠性 | 错误种子目录/空corpus ID、关闭worker、持续增加revision、过期替身、跨用例状态泄漏 | 修复测试环境；真实隔离Chroma/SQLite上传、失败补偿、删除及受控影子构建通过 |

## 验收边界

- 默认`SPARSE_BACKEND=rank_bm25_memory`保持不变；P6-A只交付代码、测试和报告。本轮没有生产generation、生产备份恢复、活动指针切换或部署操作。
- 单服务进程可合并后台请求，事务锁保护多线程；不宣称支持多个服务进程同时写库。外部CLI、换库和生产影子构建须在停写窗口操作。
- 缺少初代需要受控入口；空库保持dirty，全库BM25/Hybrid返回明确不可用。可由管理员显式切Dense或恢复旧backend，系统不静默降级。
- 固定120题在本轮用于BM25构建正确性校验。没有重新执行P4的1000篇、6独立GPU进程质量/性能对照，也没有1万篇扩展；历史性能结果保持原日期。
- P6-B仍需真实生产一致快照、120题oracle和成套恢复演练；P6-C再进行启用、完整查询回归及观察窗口。当前结果不代表已上线。
